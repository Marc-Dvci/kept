# Terms

Kept source code is MIT licensed. Kept supports customer-promise capture from support replies, delivery-risk
assessment against Jira work, human-reviewed follow-up and evidence retention. A promise state is an assessment of
the current Jira plan, not a delivery probability, contractual interpretation or guarantee.

A person confirms what was promised, the customer organisation, agreed date, timezone, owner and required work.
Customer delivery and agreed date changes require their own evidence. Source labels and URLs record provenance;
Kept does not replace the organisation's approval policy.

All customer communication uses the organisation's own channel after review. Customer delivery is distinct from
Jira task completion.

Atlassian platform and Teamwork Graph connector terms apply to installed versions. The demo data is fictional.
